# Réserve 1.0.0

Ouvrir `reserve-1.0.0.apk` sur un téléphone Android 7.0 ou supérieur. Le fichier est une version release signée avec la clé Réserve. Voir [la notice complète](../docs/LIVRAISON.md).

Le code source et les preuves se trouvent dans le dossier parent. `SHA256SUMS` permet de contrôler l'intégrité du fichier fourni. Ne pas installer sur iPhone.
